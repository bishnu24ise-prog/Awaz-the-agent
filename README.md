## ✨ What is Awaz?

**Awaz** ("voice" in Hindi/Urdu) is a voice-first Web3 agent platform running on **Monad**.

Instead of clicking through complex dashboards, users can **speak directly to the blockchain** — deploy smart contracts, interact with wallets, monitor Monad network health, execute trading workflows, and generate AI-powered audio.

Awaz ships as **"The Monad Super Agent"**: one conversational interface connecting multiple specialized Web3 and AI agents.

# ⚡ Deploy a New Contract

## Testnet

```bash
cd contracts

export PATH="$HOME/.foundry/bin:$PATH"
export PRIVATE_KEY=0xYOUR_PRIVATE_KEY

forge create src/AwazToken.sol:AwazToken \
  --rpc-url https://testnet-rpc.monad.xyz \
  --private-key $PRIVATE_KEY \
  --constructor-args 1000000000000000000000000
```

The constructor argument above represents:

```text
1,000,000 AAZ
```

with `18` decimals.

## Mainnet

```bash
cd contracts

export PATH="$HOME/.foundry/bin:$PATH"
export PRIVATE_KEY=0xYOUR_PRIVATE_KEY

forge create src/AwazToken.sol:AwazToken \
  --rpc-url https://rpc.monad.xyz \
  --private-key $PRIVATE_KEY \
  --constructor-args 1000000000000000000000000
```

# ✅ Contract Verification

Automated verification uses BlockVision's **Sourcify** endpoint.

```bash
forge verify-contract <ADDR> src/AwazToken.sol:AwazToken \
  --chain 10143 \
  --rpc-url https://testnet-rpc.monad.xyz \
  --verifier sourcify \
  --verifier-url 'https://sourcify-api-monad.blockvision.org/' \
  --constructor-args $(cast abi-encode "constructor(uint256)" 1000000000000000000000000)
```

> **Note:** Sourcify is used by the deployment tooling for source-code verification.

# 📦 Getting Started

## Prerequisites

* Node.js ≥ 18
* npm
* MetaMask
* Foundry *(required for contract deployment)*

Install Foundry and ensure it is available in your PATH:

```bash
export PATH="$HOME/.foundry/bin:$PATH"
```

## Clone

```bash
git clone https://github.com/bishnu24ise-prog/Awaz-the-agent.git
cd Awaz-the-agent
```

## Install

```bash
npm install
```

## Configure Environment

```bash
cp env.example .env.local
```

Fill in the required API keys and network configuration.

## Run

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

# 🔐 Environment Variables

| Variable                            | Purpose                                     |
| ----------------------------------- | ------------------------------------------- |
| `LLM_PROVIDER`                      | LLM provider — `groq`                       |
| `GROQ_API_KEY`                      | Groq API key                                |
| `GROQ_MODEL`                        | Model name; default `llama-3.1-8b-instant`  |
| `NEXT_PUBLIC_MONAD_RPC_URL`         | Monad Testnet RPC                           |
| `NEXT_PUBLIC_MONAD_CHAIN_ID`        | Testnet chain ID — `10143`                  |
| `NEXT_PUBLIC_MONAD_EXPLORER_URL`    | Monad Testnet explorer                      |
| `NEXT_PUBLIC_MONAD_FAUCET_URL`      | Monad faucet                                |
| `NEXT_PUBLIC_MONAD_MAINNET_RPC_URL` | Monad Mainnet RPC                           |
| `MONAD_BASELINE_GWEI`               | Baseline gas value for congestion heuristic |
| `PRIVATE_KEY`                       | Foundry deployer wallet private key         |
| `HUME_API_KEY`                      | Hume.ai API key                             |
| `HUME_SECRET_KEY`                   | Hume.ai secret key                          |

Example network configuration:

```env
LLM_PROVIDER=groq
GROQ_MODEL=llama-3.1-8b-instant

NEXT_PUBLIC_MONAD_RPC_URL=https://testnet-rpc.monad.xyz
NEXT_PUBLIC_MONAD_CHAIN_ID=10143
NEXT_PUBLIC_MONAD_EXPLORER_URL=https://testnet.monadvision.com
NEXT_PUBLIC_MONAD_FAUCET_URL=https://faucet.monad.xyz

NEXT_PUBLIC_MONAD_MAINNET_RPC_URL=https://rpc.monad.xyz

MONAD_BASELINE_GWEI=102
```

> ⚠️ **Never commit `PRIVATE_KEY`, `GROQ_API_KEY`, Hume credentials, or other secrets to GitHub.**

* `.env`, `.env.local`, and `*.env.local` should remain gitignored.
* Never commit private keys or API credentials.
* Never expose the deployer `PRIVATE_KEY` to frontend code.
* Don't run `npm run build` and `npm run dev` simultaneously because both use `.next`.
